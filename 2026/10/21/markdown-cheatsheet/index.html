Markdown 语法速查

发表于2026-10-21|更新于2026-10-21|博客速查
|浏览量:

这份只记「本站实际渲染有效」的写法：Hexo 8 + marked 渲染器 + landscape 主题，开了 breaks、smartypants 和文章资源文件夹。下面每条都在本机验证过，照抄即可。

1. 文章骨架与 front-matter

字段 作用 示例
title 标题，中文不影响 URL title: UE5 材质笔记
date 发布时间，决定网址里的年月日 date: 2026-10-21 20:00:00
updated 更新时间，不写就取文件修改时间 updated: 2026-10-21 21:00:00
categories 分类，写多个就是层级 categories: [图形学, 虚幻5]
tags 标签，可多个 tags: [材质, 着色器]
sticky 置顶，数字越大越靠前 sticky: 10

标题里有 :、#、[ 时要加引号，写成 title: "UE5: 材质"。

文件名决定网址：permalink 是 :year/:month/:day/:title/，所以 Unreal-Engine-5-Material.md + 日期 2026-10-20 就是 /2026/10/20/Unreal-Engine-5-Material/。改文件名等于改网址，发出去的文章别改名。

摘要：有 <!-- more --> 时首页只显示到它为止，再加一个 Read More 链接；没有它，首页会把整篇文章连同图片铺出来。长文一定要加。

2. 标题与段落

  • 从 ## 开始，# 留给文章标题，不要用。
  • 段落写成一行：本站 breaks: true，一个手动回车就变 <br>，会把句子从中间劈开。分段靠空行。
  • 标题会自动生成锚点，页内跳转写 [跳到表格](#8-表格)。

3. 文字样式

想要 写法
粗体 **加粗**
斜体 *斜体* 或 _斜体_
删除线 ~~删除线~~
行内代码 反引号包住，如 `Floor`
上标下标 原生不支持，写 m^2 或 H~2~O 都不行，直接用文字或图片

反引号在键盘 Esc 下面、数字 1 左边，必须是英文半角，中文输入法的全角符号不认。

4. 列表

任务列表只负责显示勾选框，页面上点不动。

5. 链接

想要 写法
外链 [文字](https://example.com)，自动在新窗口打开
站内链接 [文字](/2026/10/21/hexo-git-cheatsheet/)
页内锚点 [文字](#2-标题与段落)
直接贴地址 尖括号包住：<https://820-qqu.github.io>

6. 图片

开 post_asset_folder: true 之后，正文只写文件名，图片放进文章同名文件夹：

hexo new my-post 会同时建好 my-post.md 和 my-post\ 文件夹。注意**下划线会被转成连字符**：输入 Unreal_Engine_5_Material，文件名和文件夹名都是 Unreal-Engine-5-Material，只有 title: 保留原样。

多篇文章复用的图放 source\images\，正文写 /images/图.png（前面带斜杠）。

规矩 说明
文件名 英文小写 + 连字符，别用中文、空格、大写
大小写 GitHub Pages 跑在 Linux 上、区分大小写，Photo.PNG 本地能读线上必 404
位置 必须在 source\ 下面
体积 单文件 100 MB 上限，整站建议小于 1 GB
放大 landscape 自带 fancybox，自动生效；别自己套 [![]()]()，套了就不放大
说明文字 ![]() 里那段文字就是放大时的 caption，别空着

7. 引用、代码、折叠

代码块的语言名写错或省略会被当成纯文本，没有高亮。常用：powershell、bash、cpp、c、csharp、hlsl、js、ts、json、yaml、html、css、text、markdown。语言名后面空一格还能加标题，例如三个反引号加 cpp 示例标题。

要在一段文字里显示三个反引号，外层用四个反引号包住，这是唯一需要「套娃」的场景。

8. 表格

  • 表头行和分隔行必须紧挨着，少一行整块就退化成普通文字，页面上会看到一堆竖线。
  • 每行列数必须一致；单元格里要换行用 <br>。
  • 单元格里写竖线要转义成 \|，否则会把这一行断成多列。
  • 表格没有标题，想加就在上方单独写一行粗体说明。

9. 分割线、转义与坑

想写 直接写会怎样 正确写法
分割线 紧贴在文字下面会把上一行变成标题 单独一行 ---，前后各空一行
区间 0~1 成对出现时中间整段被划掉 0\~1，或写成「0 到 1」，或全角 ～
a*b*c b 变斜体 a\*b\*c
行首 #、1. 变标题、变列表 \#、1\.

~ 的判据：前后紧贴字符才算定界符，所以 0 ~ 1 有空格不会触发，0~1 会；同一段里出现两个才成对。另外 smartypants 会把正文里的直引号变成弯引号、把连续三个点变成省略号，中文写作里一般不用管，代码里不受影响。

10. Mermaid 流程图（本站已内置）

本站不用装插件：写一个语言标记为 mermaid 的代码块即可，页面上会画成 SVG。语言标记必须正好是小写 mermaid，代码块要顶格写，不要放进引用块里。

常用的图类型：flowchart、sequenceDiagram、classDiagram、stateDiagram-v2、erDiagram、gantt、pie、gitGraph、mindmap、timeline。

规矩 说明
中文标签 没问题
带括号的标签 用引号包住，写成 A["带括号(的文字)"]
节点 id 别用 end 这个保留字
subgraph 必须有对应的 end
箭头 --> 实线箭头、--- 实线、-.-> 虚线、==> 粗箭头

实现方式是 scripts\mermaid.js 过滤器加 source\js\mermaid.min.js（Mermaid 11.17.2，本地文件，约 3.5 MB），只有含图的页面才加载脚本，并且 skip_render 里排除了那个 min.js，不然 Hexo 会把它当页面解析。

11. 本站不支持的写法

写法 实际结果 替代
> [!NOTE] 提示块 原样显示 [!NOTE] > **注意：** 内容
脚注 [^1] 变成坏链接 正文写「注：」，或文末加注释小节
数学 $a^2$ 原样显示美元符号 用代码块或截图；要真公式得另装 KaTeX
[TOC] 原样显示 手写锚点列表
:smile: 原样显示 直接打表情

12. 发布前检查

  1. front-matter 的 title、date 有了，categories 没写错层级。
  2. 长文有 <!-- more -->。
  3. 代码围栏成对，表格列数一致。
  4. 图片名是小写英文 + 连字符，且在 source\ 目录下。
  5. hexo s 看过一遍，控制台没有红字。
  6. Test-Path public\index.html 是 True。
