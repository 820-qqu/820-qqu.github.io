虚幻5材质与节点系统笔记

发表于2026-10-20|更新于2026-10-22|图形学虚幻5
|浏览量:

这篇博客是帮助我认识UE5材质与节点系统里常见和使用的概念（示例项目是——展览馆）。

1. Floor（向下取整）

Floor（向下取整）是一个数学节点

维度 说明 举例
输入值 (Input) 节点要对什么数值进行“砍小数”操作 UV坐标、Sine（正弦波）、Time（时间）、任意标量/向量
输出值 (Output) 输出的最终数字（砍掉小数后的整数） 0.9 变 0.0；1.2 变 1.0；-0.5 变 -1.0
数学逻辑 遇到小数时往哪个方向取整 向下取整。 注意：负数会向绝对值更大的方向走，如 -1.2 变 -2.0。
阶梯数量 （配合前面乘的数值）决定切分出多少个台阶 乘以 5 后接入 Floor，会切出 0、1、2、3、4、5 共 6 个层级
视觉效果 在模型表面呈现什么视觉特征 硬边阶梯、方块、像素化、色阶断层（Posterize）
常用组合 与哪些节点搭配能产生特殊变化 配合 Frac（取小数）可做锯齿波；配合 Multiply 控制阶梯密度

1.1 节点示例连线

首先建立纹理坐标（ TexCoord ）节点，节点里的数值保持默认。然后使用 Mask（遮罩） 节点取 R （ Mask 里的 RGB 等同于 xyz，TexCoord 里的 U = x = R，同理 V = y = G），这里 Mask 节点取 R 的意思是，取 TexCoord 节点里的 U（ 0 ~ 1 ）,得到 x 轴的范围。然后使用 Multiply 节点将 Mask 节点取到的值与值 7 相乘， 得到（ 0~7 ）的 x 范围，再将得到的值通过 floor 节点向下取整，就得到了（ 0、1、2、3、4、5、6）括号里的值是整数，所以在 floor 节点的预览图下颜色的划分没有渐变。最后将得到的值通过 Divide 节点除以7，得到带有相当分明分界线的竖条格子图，就是 Divide 节点下的预览图。

1.2 它和常用节点的区别

节点名 作用 举例 (输入 1.2 / 输入 -0.5)
Floor (向下取整) 砍掉小数，只保留向下最接近的整数 1.2 -> 1.0 / -0.5 -> -1.0
Ceil (向上取整) 有小数就进位，保留向上最接近的整数 1.2 -> 2.0 / -0.5 -> 0.0
Round (四舍五入) 小数大于等于0.5进位，小于则舍去 1.2 -> 1.0 / -0.5 -> -1.0
Frac (取小数) 只保留小数点后面的数值 1.2 -> 0.2 / -0.5 -> 0.5

Floor 最常被用来把平滑的贴图（比如渐变或正弦波）切割成一块块硬朗的纯色方块。

2. Frac（取小数）

Frac（Fraction，取小数部分）节点是一个非常实用的数学工具。它的作用是只保留输入数值的小数部分，直接丢弃整数部分。

维度 说明 举例
输入值 (Input) 节点要对什么数值进行“截取小数”操作 UV坐标、Time（时间）、Sine（正弦波）、任意标量/向量
输出值 (Output) 仅保留小数点后的数值 1.25 变 0.25；3.8 变 0.8
数学逻辑 相当于 Input - Floor(Input) 输出范围固定在 0 到 < 1.0 之间（负数会被转为正数小数，如 -1.2 变 0.8）
视觉效果 在模型表面呈现什么视觉特征 无限循环的平滑渐变、锯齿波（Sawtooth）、无缝滚动
常用组合 与哪些节点搭配能产生特殊变化 配合 Time 做无限循环动画；配合 Lerp 做循环渐变

2.1 节点示例连线

首先建立纹理坐标（ TexCoord ）节点，节点里的数值保持默认，然后使用 Mask 节点取 R 的范围值，把二维空间问题降维成了一维，使得后续操作只会产生垂直的条纹。创建 Time 节点（引擎内置节点，输出游戏运行的总时间——秒，每一帧都在递增。），使用 Multiply 节点将时间乘以常量 0.5，控制动画的播放速度。然后使用 Frac 节点提取小数部分，将不断增加的时间值，截断为一个在 0.0 到 1.0 之间不断循环的锯齿波（0->1 瞬间归零），防止 Time 无限增大导致计算机浮点数精度丢失（画面卡顿），并形成了周期性的节奏。使用 Multiply 节点将上一步得到的 0 ~ 1 循环值，乘以常量 6.0，将这个周期性的数值放大 6 倍（变成 0 ~ 6 循环）。使用 Multiply 节点将上半路的“静态条纹”（A端口）与下半路的“动态时间脉冲”（B端口）相乘，当 B 接近 0 时，条纹全黑；当 B 变大时，条纹变亮。这就实现了条纹随时间的周期性闪烁或流动效果。

2.2 核心区分

节点名 作用 举例 (输入 2.7) 本质
Frac (取小数) 砍掉整数，只留小数 输出 0.7 相当于 Fmod(A, 1.0)，固定周期为 1
Fmod (取模) 除法后的余数 输入 Fmod(2.7, 2.0) 输出 0.7 周期可自定义（由 B 决定）
Floor (向下取整) 砍掉小数，只留整数 输出 2.0 总是走向更小的整数

注意：UE里的 Frac 对负数处理比较特殊，Frac(-1.2) 结果是 0.8，因为它底层实际上是 A - Floor(A)。

2.3 在材质中的应用场景

1. 无限循环滚动（无缝平铺）

如果你想让贴图一直往一个方向平移，直接用 Time 加给 UV，数值会一直变大。如果外面套一个 Frac，当 UV 到达 1.0 时，就会瞬间归零变回 0.0。这样贴图就会完美地无限循环滚动，永远不会超出边界。

2. 制作锯齿波（Sawtooth Wave）

如果你需要一种“匀速上升，然后瞬间掉落”的波形（比如雷达扫描的亮条、进度条、或者倒计时圆环），Frac(Time) 就是最完美的锯齿波发生器。

3. 极坐标（环形）重复
在做圆形阵列（比如表盘刻度、圆形赛博朋克光环）时，用 Frac 切割圆周坐标，可以轻易地让图案绕圈循环。

4. 和 Floor 的配合

在材质中，Frac 经常和 Floor 成对出现。比如你想把一排连续的渐变切成阶梯，但又想让每个阶梯里都有细微的渐变：

  • 整数部分（Floor）用来分块。
  • 小数部分（Frac）用来画块内的细节。

3. Sine（正弦波）

Sine（正弦波）节点是一个生成平滑、周期性波浪的数学节点。它非常核心，在材质中主要用来制作平滑的往复运动、周期性的脉冲以及波浪形渐变。

维度 说明 举例
输入值（Input） 决定波形的“相位”（进度） Time（时间）、UV坐标、Frac等（默认输入单位是弧度）
输出值 (Output) 输出的波浪数值 在 -1.0 到 1.0 之间平滑波动（中间值为0）
数学逻辑 平滑的三角函数循环 输入每增加约 6.28（2π），完成一次“波峰-波谷”循环
视觉效果 在模型表面呈现什么特征 平滑的渐变带、像钟摆一样的来回晃动、柔和的呼吸灯脉冲
常用组合 与哪些节点搭配能产生特殊变化 配合 Time 做动画；配合 AppendVector 做左右往复平移；配合 Abs 或 Clamp 改变波形
