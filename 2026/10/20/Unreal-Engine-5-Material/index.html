虚幻5材质与节点系统笔记

发表于2026-10-20|更新于2026-11-05|图形学虚幻5

这篇博客是帮助我认识UE5材质与节点系统里常见和使用的概念（示例项目是——展览馆）。

1. Floor（向下取整）

Floor（向下取整）是一个数学节点

维度 说明 举例
输入值 (Input) 节点要对什么数值进行“砍小数”操作 UV坐标、Sine（正弦波）、Time（时间）、任意标量/向量
输出值 (Output) 输出的最终数字（砍掉小数后的整数） 0.9 变 0.0；1.2 变 1.0；-0.5 变 -1.0
数学逻辑 遇到小数时往哪个方向取整 向下取整。 注意：负数会向绝对值更大的方向走，如 -1.2 变 -2.0。
阶梯数量 （配合前面乘的数值）决定切分出多少个台阶 乘以 5 后接入 Floor，会切出 0、1、2、3、4、5 共 6 个层级
视觉效果 在模型表面呈现什么视觉特征 硬边阶梯、方块、像素化、色阶断层（Posterize）
常用组合 与哪些节点搭配能产生特殊变化 配合 Frac（取小数）可做锯齿波；配合 Multiply 控制阶梯密度

1.1 节点示例连线

首先建立纹理坐标（ TexCoord ）节点，节点里的数值保持默认。然后使用 Mask（遮罩） 节点取 R （ Mask 里的 RGB 等同于 xyz，TexCoord 里的 U = x = R，同理 V = y = G），这里 Mask 节点取 R 的意思是，取 TexCoord 节点里的 U（ 0 ~ 1 ）,得到 x 轴的范围。然后使用 Multiply 节点将 Mask 节点取到的值与值 7 相乘， 得到（ 0~7 ）的 x 范围，再将得到的值通过 floor 节点向下取整，就得到了（ 0、1、2、3、4、5、6）括号里的值是整数，所以在 floor 节点的预览图下颜色的划分没有渐变。最后将得到的值通过 Divide 节点除以7，得到带有相当分明分界线的竖条格子图，就是 Divide 节点下的预览图。

1.2 它和常用节点的区别

节点名 作用 举例 (输入 1.2 / 输入 -0.5)
Floor (向下取整) 砍掉小数，只保留向下最接近的整数 1.2 -> 1.0 / -0.5 -> -1.0
Ceil (向上取整) 有小数就进位，保留向上最接近的整数 1.2 -> 2.0 / -0.5 -> 0.0
Round (四舍五入) 小数大于等于0.5进位，小于则舍去 1.2 -> 1.0 / -0.5 -> -1.0
Frac (取小数) 只保留小数点后面的数值 1.2 -> 0.2 / -0.5 -> 0.5

Floor 最常被用来把平滑的贴图（比如渐变或正弦波）切割成一块块硬朗的纯色方块。

2. Frac（取小数）

Frac（Fraction，取小数部分）节点是一个非常实用的数学工具。它的作用是只保留输入数值的小数部分，直接丢弃整数部分。

维度 说明 举例
输入值 (Input) 节点要对什么数值进行“截取小数”操作 UV坐标、Time（时间）、Sine（正弦波）、任意标量/向量
输出值 (Output) 仅保留小数点后的数值 1.25 变 0.25；3.8 变 0.8
数学逻辑 相当于 Input - Floor(Input) 输出范围固定在 0 到 < 1.0 之间（负数会被转为正数小数，如 -1.2 变 0.8）
视觉效果 在模型表面呈现什么视觉特征 无限循环的平滑渐变、锯齿波（Sawtooth）、无缝滚动
常用组合 与哪些节点搭配能产生特殊变化 配合 Time 做无限循环动画；配合 Lerp 做循环渐变

2.1 节点示例连线

首先建立纹理坐标（ TexCoord ）节点，节点里的数值保持默认，然后使用 Mask 节点取 R 的范围值，把二维空间问题降维成了一维，使得后续操作只会产生垂直的条纹。创建 Time 节点（引擎内置节点，输出游戏运行的总时间——秒，每一帧都在递增。），使用 Multiply 节点将时间乘以常量 0.5，控制动画的播放速度。然后使用 Frac 节点提取小数部分，将不断增加的时间值，截断为一个在 0.0 到 1.0 之间不断循环的锯齿波（0->1 瞬间归零），防止 Time 无限增大导致计算机浮点数精度丢失（画面卡顿），并形成了周期性的节奏。使用 Multiply 节点将上一步得到的 0 ~ 1 循环值，乘以常量 6.0，将这个周期性的数值放大 6 倍（变成 0 ~ 6 循环）。使用 Multiply 节点将上半路的“静态条纹”（A端口）与下半路的“动态时间脉冲”（B端口）相乘，当 B 接近 0 时，条纹全黑；当 B 变大时，条纹变亮。这就实现了条纹随时间的周期性闪烁或流动效果。

2.2 核心区分

节点名 作用 举例 (输入 2.7) 本质
Frac (取小数) 砍掉整数，只留小数 输出 0.7 相当于 Fmod(A, 1.0)，固定周期为 1
Fmod (取模) 除法后的余数 输入 Fmod(2.7, 2.0) 输出 0.7 周期可自定义（由 B 决定）
Floor (向下取整) 砍掉小数，只留整数 输出 2.0 总是走向更小的整数

注意：UE里的 Frac 对负数处理比较特殊，Frac(-1.2) 结果是 0.8，因为它底层实际上是 A - Floor(A)。

2.3 在材质中的应用场景

1. 无限循环滚动（无缝平铺）

如果你想让贴图一直往一个方向平移，直接用 Time 加给 UV，数值会一直变大。如果外面套一个 Frac，当 UV 到达 1.0 时，就会瞬间归零变回 0.0。这样贴图就会完美地无限循环滚动，永远不会超出边界。

2. 制作锯齿波（Sawtooth Wave）

如果你需要一种“匀速上升，然后瞬间掉落”的波形（比如雷达扫描的亮条、进度条、或者倒计时圆环），Frac(Time) 就是最完美的锯齿波发生器。

3. 极坐标（环形）重复
在做圆形阵列（比如表盘刻度、圆形赛博朋克光环）时，用 Frac 切割圆周坐标，可以轻易地让图案绕圈循环。

4. 和 Floor 的配合

在材质中，Frac 经常和 Floor 成对出现。比如你想把一排连续的渐变切成阶梯，但又想让每个阶梯里都有细微的渐变：

  • 整数部分（Floor）用来分块。
  • 小数部分（Frac）用来画块内的细节。

3. Sine（正弦波）

Sine（正弦波）节点是一个生成平滑、周期性波浪的数学节点。它非常核心，在材质中主要用来制作平滑的往复运动、周期性的脉冲以及波浪形渐变。

维度 说明 举例
输入值（Input） 决定波形的“相位”（进度） Time（时间）、UV坐标、Frac等（默认输入单位是弧度）
输出值 (Output) 输出的波浪数值 在 -1.0 到 1.0 之间平滑波动（中间值为0）
数学逻辑 平滑的三角函数循环 输入每增加约 6.28（2π），完成一次“波峰-波谷”循环
视觉效果 在模型表面呈现什么特征 平滑的渐变带、像钟摆一样的来回晃动、柔和的呼吸灯脉冲
常用组合 与哪些节点搭配能产生特殊变化 配合 Time 做动画；配合 AppendVector 做左右往复平移；配合 Abs 或 Clamp 改变波形

3.1节点示例连线

首先建立纹理坐标（TexCoord）节点，节点里的数值保持默认，然后使用Mask节点取R的范围值，把二维空间问题降维成了一维，使得后续操作只会产生垂直的条纹。创建Time节点（输出游戏运行的总时间——秒，每一帧都在递增。），使用Add节点将上半路的“静态坐标”（A端口）与下半路的“动态时间”（B端口）相加。相加的结果输入给Sine节点，这相当于给正弦波施加了一个随时间不断递增的“相位偏移”，让原本静止的波形产生流动感。最后，将Sine输出的 -1 ~ 1 的平滑波浪数值，直接连入材质主节点的**基础颜色（Base Color）**端口。由于颜色不能为负，负数部分会被截断为纯黑，正数部分则呈现从黑到白的平滑渐变，从而实现了黑白相间的平滑条纹随时间无缝流动的视觉效果。

3.2 核心区分

节点名 作用 举例 本质
Sine(正弦波) 生成平滑的上下波浪循环 输入约 1.57 (π/2) 输出 1.0；输入约 3.14 (π) 输出 0.0 周期性平滑波动，范围 -1 ~ 1
Cosine(余弦波) 与Sine完全相同，仅相位不同 输入 0 输出 1.0；输入约 1.57 (π/2) 输出 0.0 相当于Sine(Input + π/2)
Frac(取小数) 生成锯齿波 输入 1.2 输出 0.2 匀速上升，瞬间归零，范围 0 ~ 1，不平滑
Triangle Wave(三角波) 生成线性的上下折返 需用Abs和Frac组合搭建 匀速上升和下降，有折角，不平滑

注意：Sine和Frac最容易混淆。Frac是“直线上升然后垂直掉落”（锯齿波），而Sine是“像海浪一样平滑地起伏”（正弦波）。

3.3 在材质中的应用场景

1. 呼吸灯与脉冲（Pulse）
如果你想让自发光（Emissive）像心跳一样忽明忽暗，可以用Sine(Time)。因为输出有负数，通常会接一个Remap（重映射），把 -1 ~ 1 映射到 0 ~ 1，这样发光强度就会在“全黑”和“全亮”之间平滑过渡。

2. 周期性平移与摆动（Oscillation）
做像雷达扫描、风扇转动，或者摆钟的效果时，普通的Time会让物体一直往一个方向动。如果使用Sine(Time)并乘以一个常量，再去控制位移（如Add给UV，或连接到世界位置偏移），物体就会在起点和终点之间来回摆动。

3. 制作水波纹或波浪起伏（Wave）
将多个不同方向、不同频率的Sine波形相加（比如Sine(U) + Sine(V)），可以得到像水面一样复杂且平滑的波浪起伏。这在做水面材质、旗帜飘动、或者地形微起伏时极为常用。

4. 平滑渐变遮罩
如果你需要在一个模型表面产生一条柔和的过渡带（比如边缘发光、或者渐隐效果），利用Sine配合Saturate（截断 0~1）或Abs（取绝对值），可以快速得到没有任何硬边缘的渐变遮罩。

4. IF（条件判断）

IF节点是一个逻辑判断工具。它通过比较两个输入值，来决定最终输出什么结果。

维度 说明 举例
输入值（Input） 三个输入：A、B，以及比较条件（>、==、<） A=UV坐标，B=0.5常量
输出值 (Output) 根据条件切换输出值 条件成立输出上端口的值，否则输出下端口的值
数学逻辑 相当于编程里的if...else... A > B ? 1.0 : A
视觉效果 在模型表面呈现什么特征 硬边的分割、遮罩、二值化（非黑即白）
常用组合 与哪些节点搭配能产生特殊变化 配合Frac或TexCoord做条纹切割

4.1 节点示例连线

首先建立纹理坐标（TexCoord）节点，使用Mask节点取R的范围值，得到一个 0~1 的平滑渐变。将这个渐变接入IF节点的A端口，创建一个常量 0.5 接入B端口。在IF节点的下方分支（A>B 和 A==B），我们分别接入了两个常量：1.0 和 0.5；在最下面的分支（A<B），接回了原始的渐变输入。

最终效果： 原本平滑的黑白渐变被“切”成了两部分。大于 0.5 的区域变成了纯白（1.0），小于 0.5 的区域保留了原始的平滑渐变。

4.2 应用场景

1. 硬边遮罩： 用来抠掉模型上不需要的部分，或者制作边缘锐利的图案。
2. 阶梯化处理： 把柔和的渐变硬生生截断，形成类似卡通渲染（Toon Shading）中的硬边阴影。

5. Lerp（线性插值）

Lerp是材质中最常用的节点之一，用于在两个值之间进行平滑过渡。

维度 说明 举例
输入值（Input） A（起点）、B（终点）、Alpha（插值比例） A=蓝色，B=橙色，Alpha=0.5
输出值 (Output) 混合后的颜色或数值 50%蓝 + 50%橙 = 灰绿色（视色彩空间而定）
数学逻辑 A + Alpha × (B - A) Alpha为0输出A，为1输出B，0.5取中间值
视觉效果 在模型表面呈现什么特征 两种材质的混合、平滑的渐变、遮罩过渡
常用组合 与哪些节点搭配能产生特殊变化 配合时间、正弦波做颜色切换；配合贴图做混合

5.1 节点示例连线

上半路创建两个颜色常量（A端口为浅蓝色 0,0.88,1，B端口为深橙色 1,0.62,0）。下半路用Time驱动Sine产生一个平滑的波浪值（范围 -1 ~ 1），将其接入 Subtract的 B 端口；再用TexCoord(R)接入 A 端口。两者相减后，接入Clamp（限制在 0 ~ 1）作为遮罩。最后将Clamp的结果接入Lerp的 Alpha 端口。

最终效果： 模型表面呈现出两种颜色随正弦波平滑交替流动的视觉效果。

5.2 应用场景

1. 材质混合： 根据地形的高度（Mask）混合草地和岩石。
2. 颜色渐变： 做天空球、发光特效的渐变色彩过渡。
3. 状态切换： 做角色受击闪白效果（配合时间）。

6. OneMinus（1-x / 反向）

OneMinus节点非常简单，就是数学上的 1 - 输入值，用于反转结果。

维度 说明 举例
输入值（Input） 任意标量或向量 0.2 或 渐变
输出值 (Output) 反转后的数值 1 - 0.2 = 0.8
数学逻辑 1.0 - Input 黑的变白，白的变黑
视觉效果 在模型表面呈现什么特征 颜色反转、遮罩反向
常用组合 与哪些节点搭配能产生特殊变化 配合Lerp、Sign做反向控制

6.1 节点示例连线

上方通过TexCoord(R)乘以 2 再减去 1（范围变成 -1~1），经过Sign节点取符号（输出 -1 或 1），再接入OneMinus（-1变2，1变0，配合基础颜色实际上变成了硬边黑白的反转）。下方Time接入Sine再经过Abs取绝对值，作为Lerp的 Alpha。

最终效果： 黑白条纹随时间不断地翻转交替。

6.2 应用场景

1. 遮罩反转： 当你需要一个完全相反的遮罩时，不用重新连线，直接加个OneMinus。
2. 菲涅尔效果的内部： 调整边缘发光还是中心发光。

7. Power（幂 / 指数）

Power节点用于求幂运算，在材质中常用于调整对比度和曲线形状。

维度 说明 举例
输入值（Input） Base（底数）、Exp（指数） Base=0.5，Exp=2.0
输出值 (Output) 幂运算的结果 0.5 * 0.5=0.25
数学逻辑 当 ，小于 1 的数变小；当 ，数变大
视觉效果 在模型表面呈现什么特征 调整渐变的对比度、调整发光衰减（光晕）
常用组合 与哪些节点搭配能产生特殊变化 配合Frac的锯齿波做发光脉冲

7.1 节点示例连线

上半路用TexCoord(R)作为底数（Base）。下半路Time乘以 0.5 后经过Frac得到 0~1 的锯齿波，再乘以 7.0 放大周期，接入Power的指数（Exp）端口。

最终效果： 在模型表面，原本平滑的渐变随着时间推移，会不断产生非线性（指数级）的拉伸和收缩，表现为黑白交界处平滑地“呼吸”或动态渐变。

7.2 应用场景

1. 发光衰减： 距离发光中心越远，亮度衰减越快（指数衰减）。
2. 对比度调整： 让渐变变得更“硬”或者更“软”。

8. Sign（取符号）

Sign节点用于判断数值的正负号。

维度 说明 举例
输入值（Input） 任意标量或向量 -5.2、0、3.1
输出值 (Output) 返回值的正负号 -1.0、0.0、1.0
数学逻辑 大于0输出1，小于0输出-1，等于0输出0 剥离数值大小，只看正负
视觉效果 在模型表面呈现什么特征 绝对硬边的分割（非黑即白），无过渡
常用组合 与哪些节点搭配能产生特殊变化 配合三角函数做方波、配合减法做二值化遮罩

8.1 节点示例连线

使用TexCoord(R)获取渐变，乘以 2.0，再减去 1.0，把范围从 0 ~ 1 映射到 -1 ~ 1。将其接入Sign节点，再连入基础颜色。

最终效果： 因为中间值是 0，所以模型表面会出现一条极其锋利的黑白分界线，一半是纯黑（负值映射为黑色），一半是纯白（正值映射为白色）。

8.2 应用场景

1. 方波生成： 配合Sine或线性渐变，制造完全硬边的交替条纹。
2. 极简卡通描边： 判断法线朝向，硬切出明暗交界线。

9. Abs（绝对值）

Abs节点将输入的负数变为正数，正数保持不变。

维度 说明 举例
输入值（Input） 任意数值 -0.5、0.8
输出值 (Output) 绝对值 0.5、0.8
数学逻辑 (Input) 负数折叠成正数
视觉效果 在模型表面呈现什么特征 “折叠”波浪、波谷变波峰、双倍频率的平滑条纹
常用组合 与哪些节点搭配能产生特殊变化 配合Sine让波浪产生折角、配合位移做来回震荡

9.1 节点示例连线

TexCoord(R)加上Time接入Sine，得到平滑的正弦波，然后再接入Abs，最后连入基础颜色。

最终效果： 由于正弦波原本的负值（波谷）被绝对值“翻折”到了上面（变成波峰），原本黑下去的部分现在全亮了。视觉上条纹数量翻了一倍，且全呈现出平滑的亮部过渡。

9.2 应用场景

1. 制作来回振荡： 让物体做正弦运动时，如果不需要掉头时的减速（比如做风扇转动），加上Abs可以立刻反向。
2. 制作波纹： 将Sine和Abs配合，能快速做出模拟水波的连续亮条纹。

10. Clamp（钳制 / 限制）

Clamp节点用于限制输出范围，防止数值过大或过小。

维度 说明 举例
输入值（Input） 要限制的数值 0.8、-2.0
输出值 (Output) 处于Min和Max之间的值 若限制在 0~0.5，0.8 变 0.5，-2.0 变 0.0
数学逻辑 截断超出的范围
视觉效果 在模型表面呈现什么特征 防止过曝、去除极黑/极白、控制局部对比度
常用组合 与哪些节点搭配能产生特殊变化 配合Sine控制脉冲的最高亮度

10.1 节点示例连线

TexCoord(R)加上Time，接入Sine得到 -1~1 的连续波浪。然后接入Clamp，将Min设为 0.0，Max设为 0.2，连入基础颜色。

最终效果： 因为正弦波小于 0 的部分被死死按在了 0（纯黑），大于 0.2 的部分被按在 0.2（偏暗），最后模型上只剩下一条条非常细、非常灰暗的流动条纹，大面积是黑的。

10.2 应用场景

1. 防止过曝： 在做高光或自发光叠加时，防止数值超过 1.0 导致刺眼。
2. 提取窄带： 只让特定范围内的数值显示出来，形成细线。

11. Cosine（余弦）

Cosine节点与Sine功能相同，只是波形起始位置不同。

维度 说明 举例
输入值（Input） 决定波形相位的数值 Time、UV
输出值 (Output) 平滑的波浪数值 在 -1.0 到 1.0 之间
数学逻辑 三角函数循环 相当于Sine(Input + π/2)
视觉效果 在模型表面呈现什么特征 与Sine相同，但明暗位置有所偏移
常用组合 与哪些节点搭配能产生特殊变化 与Sine一起使用产生圆形/椭圆运动（李萨如图形）

11.1 节点示例连线

连线与Sine完全一致。TexCoord(R)加上Time，接入Cosine，连入基础颜色。

最终效果： 与正弦波非常相似。区别在于，当输入为 0 时，Sine输出 0（黑），而Cosine输出 1（白）。因此在此连线中，条纹的起始颜色和移动的相位与Sine错开了一段。

11.2 应用场景

1. 圆形运动： 如果让Cosine(Time)控制 X，Sine(Time)控制 Y，就能让 UV 或者物体做完美的圆周运动。

12. Floor（向下取整）

Floor节点会丢弃小数部分，只保留不超过该数值的最大整数。

维度 说明 举例
输入值（Input） 任意数值 3.8、-1.2
输出值 (Output) 取整后的数值 3.0、-2.0
数学逻辑 向下取整 相当于“砍掉小数”，且总是向更小的方向走
视觉效果 在模型表面呈现什么特征 色阶分离、阶梯化（马赛克效果）、切块
常用组合 与哪些节点搭配能产生特殊变化 配合Frac和除法做块状渐变、像素化滤镜

12.1 节点示例连线

TexCoord(R)乘以 7.0（放大渐变），接入Floor节点（此时渐变变成了从 0 到 7 的 8 个阶梯），然后再除以 7.0（Divide节点，把数值压回 0~1 之间），最后连入基础颜色。

最终效果： 原本非常丝滑的黑白渐变，变成了明显的 7 级台阶，视觉上类似海报化（Posterize）的色阶效果。

12.2 应用场景

1. 色阶分离（马赛克）： 把柔和的贴图变成像素风、漫画风。
2. 分块处理： 配合 UV 给模型分块赋予不同的颜色或材质。

13. Fmod（取模）

Fmod（Floating Point Remainder）用于计算除法后的余数。

维度 说明 举例
输入值（Input） A（被除数）、B（除数） A=5.2，B=2.0
输出值 (Output) 余数 5.2 除以 2 商 2 余 1.2，输出 1.2
数学逻辑 除法后取余数 类似Frac，但周期由 B 自定义
视觉效果 在模型表面呈现什么特征 自定义周期的循环、重复贴图、环形阵列
常用组合 与哪些节点搭配能产生特殊变化 配合 UV 做自定义数量的平铺

13.1 节点示例连线

上路的TexCoord(R)接入Fmod的 A 端口。下路Time乘以 0.5，经过Frac截断，再乘以 1.0（确认范围）接入Fmod的 B 端口。

最终效果： 与Frac非常相似，也是产生循环渐变。区别在于Frac是固定除以 1.0 取余数，而Fmod允许你通过 B 端口控制除数的值，从而在一个周期内产生不同数量的重复。

13.2 应用场景

1. 自定义循环数量： 如果你想在一个面片上平铺 3 次贴图，用Frac做不到，用Fmod(UV, 1/3)就可以。
2. 极坐标镜像： 在数学层面上高效地生成规则重复的阵列图案。
